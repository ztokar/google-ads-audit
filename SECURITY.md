# Security and privacy

This repository contains audit instructions and setup/query helpers, not a hosted service. The pinned official server exposes read-only reporting tools. Google OAuth credentials may permit broader access if used elsewhere; protect them accordingly.

Do not put credentials, downloaded OAuth client files, refresh tokens, customer exports or audit reports into Git, issues or pull requests. If you believe a credential has been exposed, revoke or rotate it through its provider; deleting a file or making a repository private does not undo exposure in existing clones.

For a suspected issue with this workflow, contact the maintainer privately through https://israelseofreelancer.com/. Describe the affected component and impact without including a token, password or private account data. Report problems in the official Google Ads MCP server to its upstream project using that project's reporting process.

The workflow cannot guarantee that an account's tracking is accurate or that every dependency is free of vulnerabilities. Verify the selected account, the tool inventory and the purchase evidence before using an audit to change spending.
