# An illustrative purchase-aware audit

**Fictional example. Every number on this page is invented to demonstrate the output. This is not a client result or a promise of performance.**

## What the account reports

| Measure | Demo value |
|---|---:|
| Ad spend | $2,400 |
| All conversion events | 220 |
| Purchase credits | 40 |
| Call events | 20 |
| Cart events | 160 |
| Purchase conversion value | $7,200 |
| Reported purchase ROAS | 3.00x |

The 220 events are not 220 sales. Purchases, calls and cart events must be separated. Purchase credits are not automatically unique paid orders.

## What identifiable brand removal changes

| Measure | Identifiable brand | Remaining traffic |
|---|---:|---:|
| Spend | $400 | $2,000 |
| Purchase credits | 28 | 12 |
| Purchase value | $5,100 | $2,100 |
| Reported purchase ROAS | 12.75x | 1.05x |

This is a demonstration of identifiable brand removal, not proof all remaining traffic is non-brand or incremental. Hidden terms remain unknown. Cost and value reconcile across both columns to the account totals.

## What we can and cannot conclude

The reported account-wide 3.00x return includes strong brand attribution. Remaining traffic has a much weaker 1.05x attributed return in this fictional example. Calls and cart events do not establish sales. No order-level store verification has been provided, so actual paid-order revenue, refunds, cancellations and incremental sales remain unverified.

Next steps: verify purchases against paid orders, agree an acquisition target using the real product margin, then review the campaign and query evidence before increasing spend. No automatic edits or spending occur.
