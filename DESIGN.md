# Repository presentation

Audience: business owners and consultants exploring a Google Ads audit workflow. Job: show the distinction between conversion totals and purchase evidence, make setup approachable, and offer a real contact path for help.

Visual direction: editorial evidence. Off-white #f7f8fb, navy #10213b, blue #2457ff. One wide generated cover illustration with legible title, one deterministic workflow diagram, native Markdown tables and short sections. GitHub owns page typography; do not rely on unsupported styling.

Illustrations do not claim to be product screenshots. Every example number is explicitly fictional. No client screenshots, endorsements, Google/OpenAI logos, invented outcomes or conversion promises. Relative images must work on GitHub and in a local preview. Small-screen text should remain understandable with meaningful alt text and supporting native copy.

Cover image: generated with the built-in image-generation tool and saved at assets/cover.png. Prompt: premium editorial wide GitHub cover for Google Ads Audit; off-white paper, navy and royal blue; exact text Google Ads Audit, Know what your ads actually produced., Built for Codex; abstract report panels and a magnifying glass; generous safe margins; no official logos, robot, real dashboard or numerical performance claims.
